Parameter Explanations

Population

The total population of the metro area. Default is Minneapolis-St. Paul metro (3.3M people). This determines total food storage needs.

Days of Buffer Storage

How many days of food supply to keep in reserve. 90 days (3 months) provides significant resilience for winter disruptions or supply chain issues.

Packing Efficiency

The percentage of container volume that can actually be used for food storage. Typical value is 75% (0.75), accounting for pallets, air circulation, and access space.

Unit Dimensions

The physical size of each storage container. Standard 20ft reefers are 20×8×8.5 ft. High-cube 40ft reefers are 40×8×9.5 ft.

Unit Cost

The purchase cost per refrigerated container. Typical range: $8,000-$15,000 for used 20ft units, $10,000-$20,000 for used 40ft units. New units cost significantly more ($20,000-$40,000).

Daily Operating Cost

The cost to run each unit per day, including electricity, maintenance, and monitoring. Typical range: $5-$15/day depending on electricity rates, climate, and unit efficiency.

Model Assumptions

Based on 2,000 lbs/person/year consumption, 45% requiring refrigeration, 30 lbs/ft³ food density, and 40% warehouse efficiency for traditional storage.

Use Case

This calculator helps plan distributed refrigerated storage networks using standard shipping containers (reefers) as modular cold storage units throughout a metro area.

Mathematical Model

Step 1: Calculate Total Food Storage Need

$$L_{total} = P \times C_{annual} \times R_{cold}$$
Where: P = Population, Cannual = 2,000 lbs/person/year, Rcold = 0.45 (45% needs refrigeration)

Step 2: Calculate Buffer Storage Amount

$$L_{buffer} = L_{total} \times \frac{D_{buffer}}{365}$$
Where: Dbuffer = Days of buffer storage (e.g., 90 days)

Step 3: Convert to Volume

$$V_{food} = \frac{L_{buffer}}{\rho_{food}}$$
Where: ρfood = 30 lbs/ft³ (food density)

Step 4: Calculate Total Warehouse Volume

$$V_{gross} = \frac{V_{food}}{E_{warehouse}}$$
Where: Ewarehouse = 0.40 (40% warehouse efficiency for traditional storage)

Step 5: Calculate Individual Unit Capacity

$$V_{unit} = L_{unit} \times W_{unit} \times H_{unit} \times E_{packing}$$
Where: L, W, H = Unit dimensions, Epacking = Packing efficiency (typically 0.75)

Step 6: Calculate Number of Units Required

$$N_{units} = \lceil \frac{V_{food}}{V_{unit}} \rceil$$
Ceiling function ensures we round up to whole units

Step 7: Calculate Costs

$$C_{capital} = N_{units} \times C_{unit}$$ $$C_{annual} = N_{units} \times C_{daily} \times 365$$ $$C_{5year} = C_{capital} + (5 \times C_{annual})$$
Where: Cunit = Cost per unit, Cdaily = Daily operating cost per unit
